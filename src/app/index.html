Print the bone, straight from the CT.

Drop a CT study and get a clean, watertight bone model sized for the Bambu A1. Files are anonymised and converted on this device — they never leave your browser.

Drop a CT folder, DICOM files or a .zip here

The whole CD / export folder is fine — the right series is picked automatically.

Reading files…

  1. Anonymise. Names, IDs, dates and every other identifying tag are discarded as each file is read. Only the image geometry and pixel values are kept — in memory, on this device.
  2. Find the bone. The best series, the bone threshold, smoothing and clean-up are chosen automatically. Sliders are there if you want to adjust.
  3. Print. Download an STL (or 3MF) at true size in millimetres, solid and in one piece, ready for Bambu Studio.

For education, surgical planning aids and patient communication. Not a medical device and not for diagnosis — always check the model against the original images.

Print size

STL opens in every slicer. 3MF is smaller and carries millimetre units — Bambu Studio will say it “is not from Bambu Lab”; choose to load the geometry.

Bambu A1 print tips
  • In Bambu Studio use Auto orient or Lay on face, then enable tree supports (auto).
  • 0.16 mm layers and 3 walls give crisp cortical detail; 10–15 % gyroid infill is plenty.
  • PLA is ideal. Add a brim if only a small area touches the plate.
  • Thin plates (scapula blade, orbital walls) print best with “Arachne” wall generator, which is the default.
